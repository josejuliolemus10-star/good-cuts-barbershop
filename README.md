# Good Cuts Barber Shop - Landing Page

Landing Page moderna, minimalista y de alto impacto para **Good Cuts Barber Shop**, construida con un diseno boutique de lujo basado en la paleta oscura Pantone (`#101820`, `#161A2B`, `#454546`, `#A8A9AD` y acentos `#E5C158`).

## Caracteristicas
- **Efecto App Wrapper**: Diseno tipo tarjeta flotante con bordes superiores redondeados (`rounded-t-[2.5rem]`).
- **Navbar Flotante**: Logotipo minimalista, barra de navegacion central en capsula translucida y boton de llamado a la accion.
- **Hero & Galeria Dinamica**: 5 tarjetas intercaladas de corte cinematografico con mascara de desvanecimiento lateral en CSS.
- **Menu Tarifario**: 3 paquetes con etiquetas estilo "pill" y destaque para la oferta especial.
- **Modulo de Reservas**: Seleccion interactiva de sede, calendario horizontal con navegacion asistida y selector de horarios laborales en tiempo real.
- **Resenas Masonry**: Diseno escalonado simulando carrusel infinito con testimonios y avatares de clientes.
- **Preguntas Frecuentes**: Acordeones funcionales nativos (`<details>` y `<summary>`).

## Tecnologias
- HTML5 Semantico
- Tailwind CSS via CDN
- JavaScript Nativo (Vanilla JS)
- Google Fonts (Inter + Playfair Display)
- Iconos SVG puros (sin emojis)
